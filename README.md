# Personal Resource Bar

A modern-style personal health and resource display for WotLK 3.3.5a
private servers.

It shows a green health bar with the active power bar stacked underneath —
mana blue, rage red, energy yellow, runic power light blue — each with
right-aligned text and a spark at the fill edge. The power color follows
the live power type, so a Druid's bar switches from blue to yellow to red
as it shifts forms, with no setup.

Classes with a secondary resource get it automatically, as a row of orbs
under the bars:

- **Rogue** — 5 combo points
- **Druid** — 5 combo points, only while in Cat Form
- **Death Knight** — 6 runes colored by type (Blood / Unholy / Frost / Death), dimmed with a cooldown swipe while recharging

Every other class (Warrior, Paladin, Hunter, Priest, Shaman, Mage,
Warlock) gets just the two bars in the right colors.

The 3.3.5a client has no API for attaching frames to nameplates, so the
bars sit wherever you put them on screen rather than under your
character's feet.

## Install

Copy the `PersonalResourceBar` folder into `Interface/AddOns/` in your
3.3.5a client, then enable it on the character-select AddOns screen.

## Usage

- `/prb` — open the options panel (also under Interface → AddOns)
- `/prb unlock` — unlock the bars, then drag them (they highlight green while unlocked)
- `/prb lock` — lock them back in place
- `/prb reset` — reset position, size and colors
- `/prb help` — list the commands

The options panel covers width, both bar heights, orb size, scale, bar
texture, the spark, and a color picker for the health bar and for
whichever resource you currently use. Health and resource text can each be
set to Auto, Percent, Value, Value + percent, or Hidden — Auto shows
health and mana as a percentage and generated resources (rage, energy,
runic power) as the number itself. Settings are saved per character.

## Artwork

The combo point and rune orbs are TGA files in `PersonalResourceBar/Media`,
generated by `tools/make_orb_textures.py`. The fill is drawn white and
tinted in-game, so one texture covers every resource color. Re-run that
script to change the look:

```
python3 tools/make_orb_textures.py
```

## Compatibility

Written against the 3.3.5a API only. It avoids calls added in later
expansions (`UNIT_POWER`, `SetShown`, `BackdropTemplate` and friends), and
polls health and power ten times a second alongside the unit events, so it
keeps working on cores that don't fire every event reliably.
